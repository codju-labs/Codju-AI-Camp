Types of Games

Your genre tells AI what kind of rules, controls, and screens to create.

Genre map

Six Game Shapes

run

Endless runner

Move, dodge, collect, survive longer each try.

puz

Puzzle

Solve a challenge with logic, clues, or matching.

arc

Arcade

Fast action, simple controls, score chasing.

sim

Simulation

Manage a system like a shop, city, garden, or team.

quiz

Quiz

Answer questions, earn points, learn as you play.

adv

Adventure

Explore, collect items, unlock story moments.

Prompt tip

Name the Genre First

say

A strong first sentence

Start your AI prompt like this: Build a browser-based endless runner game… or Build a memory puzzle game…

That one phrase gives AI the right mental model before you add details.
