The Building Blocks

FE

Frontend & Backend

Frontend is everything you see and click: the layout, colours, buttons. Backend is the hidden engine that remembers logins, saves orders and does the thinking.

Frontend = the shop floor. Backend = the storeroom and staff behind the scenes.

DB

Databases

A database safely stores everything a site must remember: user accounts, orders, feedback, student details. Anything that changes or grows lives here.

Popular databases: MySQL, PostgreSQL, MongoDB. AI tools like Lovable can add one for you.

srv

Servers & Hosting

A server is an always-on computer that holds your site. Hosting means renting space on one so anyone can visit, day or night.

Beginner-friendly hosts: Vercel and Netlify. Many AI builders publish to them in one click.

dom

Domain Names

A domain is your site’s easy-to-remember address, like codju.com. Behind it, computers actually use a number called an IP address — the domain is the friendly name for it.

Endings: .com, .in, .org, .edu. Buy one from GoDaddy or Namecheap in 3 steps: search if it’s free, purchase it, register your ownership.
